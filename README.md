# Federated Survival Random Forest for Partially overlapping Data

frsf is a python implementation of the Federated Survival Random Forest.

## Installation

### Dependencies

frsf requires:
- numpy (>=2.0.0)
- pandas (>=2.3.0)
- scikit-learn(>=1.8.0)
- scikit-survival (>=0.27.0)
